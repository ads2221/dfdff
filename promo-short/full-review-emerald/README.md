# DCA Solana Trade — полный обзор (Emerald, новый сайт)

Полный обзор обновлённой платформы в формате ПК: 1920×1080, 30 fps, ~7,6 мин. Весь ролик в изумрудной (Emerald) теме. В кадре виден курсор, который управляет интерфейсом.

## Файлы
- `dca_solana_trade_review_emerald_1080p.mp4` — финальное видео (сжато, чтобы уложиться в лимит GitHub).
- `thumbnail/` — превью A / B / C в 1920×1080 и 1280×720, а также HTML-шаблоны.
- `audio/` — сценарий (`script.txt`), озвучка по главам (`vo/cNN.mp3` + выравнивание), проверка распознаванием (`stt.txt`).
- `source/` — композиция `comp.html` + `engine.js` (детерминированный рендер `renderAt(t)`), раскадровка `shots.js`, скриншоты (`a/` — веб-панель, `a3/` — мини-приложение).
- `scripts/` — подготовка ассетов, TTS, сведение, рендер; `capture/` — скрипты съёмки сайта и мини-приложения в теме Emerald.

## Озвучка
Используется голос ElevenLabs «Liam» на модели `eleven_v4` с ударениями (U+0301). Ключ берётся из переменной окружения `ELEVENLABS_API_KEY`, в репозитории его нет.

## Пересборка
Выполнять в папке со скриптами и исходниками:

```
python3 prep.py
node events.mjs
python3 mix_long.py
W=4 node render.mjs
```

Затем склеить `seg*.mp4` и наложить `mix.wav`.
