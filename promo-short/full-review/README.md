# DCA Solana Trade — полный обзор платформы (ПК-версия, 1920×1080)

**`dca_solana_trade_full_review_1080p.mp4`** — 9 мин 59 с, 1920×1080, 30 fps, голос ElevenLabs (Brian, multilingual v2), −14 LUFS.
Версия для репозитория сжата под лимит GitHub (≤100 МБ); `excerpt_monitoring_hq.mp4` — отрывок главы «Мониторинг» в мастер-качестве.

Формат — запись экрана ПК-версии: окно браузера с реальной веб-панелью, анимированный курсор (наведение, клики по меню и кнопкам,
прокрутка колесом), подсветка блоков с наездом камеры, заставки глав, шкала глав слева, субтитры по словам.
Мини-приложение показано в окне Telegram Desktop: чат с ботом → «Открыть» → вкладки, выноски, смена тем.

## Как устроено
- `scripts/desk_cap.mjs`, `desk_extra.mjs`, `desk_targets.mjs` — съёмка разделов панели (1600×1000 @1.5x), координаты блоков и кнопок.
- `source/shots.js` — сценарий действий по главам (переходы, клики, прокрутка, подсветка), привязанный к словам озвучки.
- `source/engine.js` — детерминированный рендер кадра `renderAt(t)`; `scripts/render.mjs` — покадровый рендер в 4 потока.
- `scripts/tts_long.py` — озвучка по главам (`ELEVENLABS_API_KEY` из окружения), `scripts/mix_long.py` — сведение голоса, музыки и звуков кликов.
