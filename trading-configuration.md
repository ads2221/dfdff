# Настройки торговли

## Введение

Настройки торговли - это ключевой раздел для настройки поведения вашей торговли. Здесь вы управляете всеми параметрами, которые влияют на открытие и закрытие ордеров.

## Основные параметры

### Размер позиции (Trade Amount)

Это размер позиции по умолчанию при открытии ордера в USD.

**Как изменить:**
1. Откройте **⚙️ Настройки → Настройки торговли → Размер позиции**
2. Введите новую сумму
3. Сохраните

**Примеры:**
- $10 - для новичков
- $50 - для среднего торговца
- $100 - для агрессивной торговли

### Базовая валюта

Валюта, которой вы платите за покупку токенов.

- **SOL** - рекомендуется (быстро, дешево)
- **USDC** - стабильная валюта

## Параметры свапа

### Проскальзывание (Slippage)

Проскальзывание - это максимальный процент отклонения от ожидаемой цены, который вы принимаете.

**Как работает:**
- Ботстановит лимит цены
- Если цена отклоняется более чем на этот процент, своп отменяется
- Минимальный лимит защищает вас от плохих цен

**Рекомендуемые значения:**

| Проскальзывание | Рекомендация | Когда использовать |
|-----------------|--------------|-------------------|
| 20 bps (0.2%) | Обычно | Стабильные токены |
| 50 bps (0.5%) | Часто | Средняя волатильность |
| 100 bps (1%) | Редко | Высокая волатильность |
| 200 bps (2%) | Только если нужно | Экстремальная волатильность |

**Как выставить:**
1. Откройте **Настройки торговли → Проскальзывание**
2. Выберите значение из списка или введите свое
3. Сохраните

### Автоматическое проскальзывание (Auto Slippage)

Если эта функция включена, бот автоматически подбирает проскальзывание для успеха своп.

**Как работает:**
1. Начинает со значения "Минимум"
2. Если своп не прошел, повышает проскальзывание
3. Повторяет попытку
4. Останавливается, когда достигнет максимума

**Преимущества:**
- Автоматически подбирает оптимальное проскальзывание
- Увеличивает вероятность успешного свапа
- Экономит время

**Как включить:**
1. Откройте **Настройки торговли → Автоматическое проскальзывание**
2. Нажмите **Включить**
3. Установите:
   - **Минимум:** 20 bps
   - **Максимум:** 50 bps
4. Сохраните

### Выбор DEX (Decentralized Exchange)

Выберите, какой DEX использовать для свапов:

- **Jupiter** - рекомендуется (лучшие цены)
- **Raydium** - альтернатива

**Как выбрать:**
1. Откройте **Настройки торговли → DEX**
2. Выберите **Jupiter** или **Raydium**
3. Сохраните

## Параметры закрытия позиции

### Автоматическое закрытие по времени

Бот может автоматически закрывать ордера по установленному времени.

**Как работает:**
1. Вы устанавливаете время (например, 480 минут = 8 часов)
2. Ордер остаётся открытым указанное время
3. По истечению времени бот автоматически его закрывает

**Как включить:**
1. Откройте **Настройки торговли → Автозакрытие по времени**
2. Нажмите **Включить**
3. Установите время в минутах:
   - 60 минут = 1 час
   - 240 минут = 4 часа
   - 480 минут = 8 часов
   - 1440 минут = 24 часа
4. Сохраните

### Закрытие раньше установленного времени

Если вы хотите закрывать позицию раньше, используйте раннее закрытие:

1. Откройте **Настройки торговли → Раннее закрытие**
2. Установите, на сколько минут раньше закрывать (например, 30)
3. Сохраните

**Пример:**
- Автозакрытие: 480 минут (8 часов)
- Раннее закрытие: 30 минут раньше
- Ордер закроется через 450 минут (7.5 часов)

## Пределы позиций

### Максимальная сумма ордера

Установите максимальный размер позиции для защиты:

**Как выставить:**
1. Откройте **Настройки торговли → Максимальный размер ордера**
2. Введите максимальную сумму в USD
3. Нажмите **Применить** (оставьте пусто для отключения)
4. Сохраните

**Пример:**
- Размер позиции: $50
- Максимум: $100
- Бот не откроет ордер больше $100

## Расширенные параметры

### Режим Ultra API

Это специальный режим для быстрого исполнения свапов.

**Как включить:**
1. Откройте **Настройки торговли → Расширенные → Ultra API**
2. Нажмите **Включить**
3. Сохраните

**Преимущества:**
- Быстрое исполнение свапов
- Лучшие цены
- Меньше сбоев

### Автоматическая коррекция суммы

Автоматически подбирает размер позиции на основе параметров токена.

**Как включить:**
1. Откройте **Настройки торговли → Расширенные → Автокоррекция суммы**
2. Нажмите **Включить**
3. Сохраните

### Задержка перед свапом

Добавляет задержку перед выполнением свапа.

**Как выставить:**
1. Откройте **Настройки торговли → Расширенные → Задержка свапа**
2. Введите время в секундах
3. Сохраните

**Примеры:**
- 0 секунд - без задержки (обычно)
- 5 секунд - небольшая задержка
- 30 секунд - большая задержка (для анализа)

## Автоматический своп SOL

### Что такое автосвап SOL

Если ваше количество SOL падает ниже установленного уровня, бот автоматически свапит USDC на SOL.

**Как включить:**
1. Откройте **Настройки торговли → Автосвап SOL**
2. Нажмите **Включить автосвап**
3. Установите:
   - **Порог:** когда активировать своп (например, когда SOL < $2)
   - **Сумма для свапа:** сколько USDC свапить на SOL (например, $10)
4. Сохраните

**Работа:**
- Бот проверяет баланс SOL каждый час
- Если SOL меньше порога, автоматически свапит нужную сумму USDC на SOL
- После успешного свапа вы получаете уведомление

### Пример конфигурации

Допустим, вы хотите:
- Закрывать позицию при падении SOL до $1.50
- При этом автоматически получить $10 USDC в виде SOL

1. Установите **Порог:** $1.50
2. Установите **Сумма:** $10
3. Сохраните

## Фильтры токенов

### Минимальная капитализация (Min MCap)

Не открывать позиции по токенам с капитализацией ниже этой суммы.

**Как выставить:**
1. Откройте **Настройки торговли → Фильтры → Min MCap**
2. Введите минимальную капитализацию
3. Сохраните

### Максимальная капитализация (Max MCap)

Не открывать позиции по токенам с капитализацией выше этой суммы.

### Минимальная ликвидность (Min Liquidity)

Требовать минимум ликвидности для открытия позиции.

**Рекомендация:** $150,000 - $200,000 для стабильности

## Параметры ETA (Estimated Time of Action)

### Минимальное и максимальное ETA

- **Min ETA:** минимальное время (в минутах) до события
- **Max ETA:** максимальное время до события

**Как выставить:**
1. Откройте **Настройки торговли → Фильтры → ETA**
2. Установите минимум и максимум
3. Сохраните

## Сохранение и применение

### Сохранить изменения

После изменения любых параметров обязательно:

1. Нажмите кнопку **✅ Сохранить**
2. Бот подтвердит сохранение
3. Новые параметры применятся к будущим ордерам

### Сброс на значения по умолчанию

Если хотите вернуть стандартные значения:

1. Откройте **Настройки торговли**
2. Нажмите **⚙️ Дополнительно → Сброс**
3. Выберите **Сбросить на значения по умолчанию**
4. Подтвердите

## Советы по оптимизации

1. **Начните с консервативных значений:**
   - Проскальзывание: 50 bps
   - Размер позиции: $10-$50
   - Максимум: в 2 раза больше стандартного

2. **Постепенно увеличивайте размер:**
   - После 10 успешных сделок увеличьте размер на 50%
   - После 50 сделок увеличьте еще

3. **Настраивайте по результатам:**
   - Если часто срабатывает лимит проскальзывания - повысьте его
   - Если часто теряете деньги - сделайте фильтры строже

---

**Важно:** Сохраняйте все изменения, нажимая **✅ Сохранить**, иначе они не применятся!
