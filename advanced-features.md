# Расширенные функции

## Введение

Расширенные функции предназначены для опытных пользователей, которые хотят максимизировать свои результаты и иметь больше контроля над торговлей.

## Режим Ultra API

### Что это такое

Режим Ultra API использует оптимизированные методы для выполнения свапов с лучшими результатами.

**Преимущества:**
- Быстрое исполнение свапов
- Лучшие цены
- Меньше сбоев и ошибок
- Выше вероятность успеха

**Недостатки:**
- Может быть недоступным в некоторых сетях
- Требует дополнительной конфигурации

### Как включить

1. Откройте **Настройки → Расширенные → Режим Ultra API**
2. Нажмите **Включить**
3. Сохраните

**Рекомендация:** Включайте этот режим для улучшения качества исполнения.

## Jito и Nozomi

### Что это такое

Jito и Nozomi - это услуги приоритета выполнения транзакций на Solana.

**Как работают:**
- Вы платите дополнительную комиссию (MEV-комиссия)
- Ваша транзакция выполняется с более высоким приоритетом
- Меньше сбоев, быстрее исполнение

### Когда использовать

- Когда сеть Solana перегружена
- Для критичных сделок
- Когда нужно гарантировать исполнение

### Как включить Jito

1. Откройте **Настройки → Расширенные → Jupiter Settings**
2. Найдите **Jito Enabled**
3. Нажмите **Включить**
4. Установите комиссию:
   - Минимум: 1,000,000 лямпортов (~$0.5)
   - Рекомендуется: 2,000,000 лямпортов (~$1)
   - Максимум: 5,000,000 лямпортов (~$2.5)
5. Сохраните

### Как включить Nozomi

1. Откройте **Настройки → Расширенные → Jupiter Settings**
2. Найдите **Nozomi Enabled**
3. Нажмите **Включить**
4. Установите комиссию:
   - Рекомендуется: 1,500,000 лямпортов (~$0.75)
5. Сохраните

**Сравнение:**

| Параметр | Jito | Nozomi |
|----------|------|--------|
| Скорость | Очень быстро | Быстро |
| Надёжность | Высокая | Средняя |
| Комиссия | Выше | Ниже |
| Рекомендуется | Критичные | Обычные |

## Приватные ключи и безопасность

### Форматы приватных ключей

Приватный ключ может быть в разных форматах:

1. **Base58** - стандартный формат Solana (рекомендуется)
   - Пример: `3K3xk...` (длинная строка)
   - Скопируйте из кошелька Phantom или Solflare

2. **Hex** - шестнадцатеричный формат
   - Пример: `a1b2c3d4...`
   - Реже используется

### Как конвертировать ключ

Если у вас ключ в неправильном формате, бот может помочь:

1. Откройте **Настройки → Расширенные → Конвертер ключей**
2. Вставьте ключ
3. Выберите исходный формат
4. Нажмите **Конвертировать**
5. Скопируйте результат

## Расширенные фильтры

### Специфичные правила для токенов

Вы можете создать специальные правила для конкретных токенов.

**Примеры:**
- Никогда не открывать позицию > $50 по токену X
- Для токена Y требовать Potential Price Change > 100%
- Для токена Z закрывать позицию за 2 часа

### Как добавить

1. Откройте **Фильтры → Расширенные → Специфичные правила**
2. Нажмите **Добавить правило**
3. Введите:
   - **CA (Contract Address):** адрес токена
   - **Название:** описание (опционально)
   - **Правила:** установите специальные фильтры
4. Сохраните

## Минимальное изменение цены (Min Price Change)

### Что это такое

Правила для минимального изменения цены для конкретных токенов.

**Примеры:**
- Для стабильных токенов требовать 50%+
- Для волатильных токенов требовать 100%+
- Для известных токенов требовать 10%+

### Как добавить

1. Откройте **Фильтры → Расширенные → Минимальное изменение цены**
2. Нажмите **Добавить правило**
3. Установите:
   - **CA:** адрес токена
   - **Минимум:** требуемое изменение в %
4. Сохраните

## Задержка перед свапом (Swap Delay)

### Что это такое

Добавляет задержку перед выполнением свапа. Полезно для анализа или если вы хотите отменить сделку перед исполнением.

### Как выставить

1. Откройте **Настройки → Расширенные → Задержка свапа**
2. Введите время в секундах:
   - 0 = без задержки (обычно)
   - 5-10 = небольшая задержка
   - 30-60 = большая задержка (время подумать)
3. Сохраните

**Пример:**
- Вы открываете позицию
- Бот ждёт 10 секунд
- За это время вы можете нажать "Отмена" если захотите
- После 10 секунд своп выполняется автоматически

## Профит-шер (Profit Share)

### Что это такое

Специальный тип подписки, при котором вы платите меньше, но делитесь 50% прибыли с владельцем бота.

**Как работает:**
1. Вы платите меньшую начальную сумму
2. При закрытии позиции с прибылью
3. 50% прибыли автоматически переводится владельцу бота
4. 50% прибыли остаётся вам

**Пример:**
- Вы открыли позицию на $100
- Закрыли с прибылью $20
- Вам остаётся: $100 + $10 = $110
- Владельцу переводится: $10

### Как активировать

1. Откройте **Профиль → Подписка**
2. Нажмите **Выбрать Profit Share**
3. Введите адрес кошелька для получения прибыли
4. Подтвердите

### История переводов

Вы можете посмотреть все переводы прибыли:

1. Откройте **Профиль → История Profit Share**
2. Увидите список всех переводов с датой и суммой

## Таблица лидеров (Leaderboard)

### Что это такое

Таблица, показывающая лучших трейдеров по различным метрикам.

**Метрики:**
- Общая прибыль
- Процент выигрышей
- Количество сделок
- Среднее время жизни ордера

### Как получить доступ

1. Откройте **Главная панель → Статистика**
2. Нажмите **Таблица лидеров**
3. Выберите метрику для сортировки

### Как улучшить ваш рейтинг

- Увеличивайте общую прибыль
- Повышайте процент выигрышей
- Делайте больше сделок
- Оптимизируйте время жизни ордера

## Экспорт и импорт данных

### Экспорт данных

Вы можете экспортировать свои данные:

1. Откройте **Настройки → Расширенные → Экспорт**
2. Выберите, что экспортировать:
   - ✓ История торговли
   - ✓ Настройки фильтров
   - ✓ Открытые ордера
   - ✓ Профиль
3. Нажмите **Экспортировать**
4. Бот отправит вам файл

**Форматы:**
- JSON - для переноса в другой бот
- CSV - для анализа в Excel
- PDF - для печати/архива

### Импорт данных

Вы можете импортировать данные:

1. Откройте **Настройки → Расширенные → Импорт**
2. Выберите файл для импорта
3. Выберите, что импортировать
4. Подтвердите

## Уведомления PnL

### Когда отправляются уведомления

Бот может отправлять уведомления о значимых изменениях PnL:

**Примеры:**
- +5% прибыль
- +10% прибыль
- -5% убыток
- -10% убыток

### Как настроить

1. Откройте **Настройки → Уведомления → PnL уведомления**
2. Включите опцию
3. Установите пороги:
   - Положительные пороги (прибыль): +5%, +10%, +25%
   - Отрицательные пороги (убыток): -5%, -10%, -25%
4. Сохраните

### Типы уведомлений

- **В боте** - сообщение в чат
- **Popup** - всплывающее окно
- **Звук** - звуковое уведомление (если включено)

## Статистика и аналитика

### Подробная аналитика

Получите детальный анализ вашей торговли:

1. Откройте **Статистика → Подробная аналитика**
2. Увидите:
   - Процент выигрышей
   - Коэффициент риска/награды
   - Максимальная прибыль/убыток
   - Среднее время жизни ордера
   - И многое другое

### Фильтрация по датам

Анализируйте торговлю за определённый период:

1. Откройте **Статистика → Выбрать период**
2. Выберите:
   - **За день** - последние 24 часа
   - **За неделю** - последние 7 дней
   - **За месяц** - последние 30 дней
   - **Пользовательский** - выберите даты
3. Посмотрите результаты

## API и интеграции

### Если вы разработчик

Бот может предоставить API для интеграции:

1. Откройте **Настройки → Расширенные → API**
2. Нажмите **Создать API ключ**
3. Копируйте ключ (храните в безопасности!)
4. Используйте для интеграции

**Важно:** Никогда не делитесь API ключом ни с кем.
