# Главное меню и основные операции

## Главная панель (Main Menu)

Главная панель - это ваш основной инструмент управления ботом. При нажатии на кнопку **🏠 Главная панель** откроется основное меню со следующими опциями:

### Доступные опции

#### 📋 Открытые ордера (Open Orders)

Показывает список всех ваших активных позиций. Для каждого ордера вы увидите:

- **Название токена** - символ токена
- **Сумма сделки** - размер вашей позиции в USD
- **Текущая цена** - актуальная цена токена
- **Прибыль/Убыток (PnL)** - текущий результат позиции в USD и процентах
- **Время открытия** - когда была открыта позиция
- **Время до закрытия** - осталось до автоматического закрытия

**Действия с ордерами:**

- Нажмите на ордер для получения подробной информации
- Используйте кнопку **Закрыть позицию** для закрытия ордера
- Используйте **Закрыть частично** для частичного закрытия

#### 👤 Профиль (Profile)

Показывает вашу информацию и статистику:

- **Имя и фамилия** - ваши личные данные
- **ID пользователя** - уникальный идентификатор в боте
- **Дата регистрации** - когда вы присоединились
- **Адрес кошелька** - ваш адрес в Solana
- **Статус подписки** - тип и срок действия подписки

**Статистика:**

- **Всего сделок** - количество совершённых сделок
- **Общий объём** - сумма всех торговых операций
- **Общая прибыль/убыток** - результат всех сделок
- **Процент прибыльных сделок** - ваш процент выигрышей (Win Rate)

#### ⚙️ Настройки (Settings)

Главное меню настроек, содержит:

- **Настройки кошелька** - управление кошельком
- **Настройки торговли** - параметры торговли
- **Фильтры токенов** - критерии отбора
- **Автоматизация** - автоматические действия
- **Расширенные настройки** - продвинутые функции
- **Черный список** - управление чёрным списком

#### 📊 Статистика (Statistics)

Показывает детальную статистику вашей торговли:

- **Общие показатели** - суммарная статистика
- **За день** - статистика за последний день
- **За неделю** - статистика за неделю
- **За месяц** - статистика за месяц

Включает:
- Количество открытых ордеров
- Количество закрытых ордеров
- Средняя прибыль/убыток
- Процент выигрышей
- Общий объём торговли

#### ℹ️ Помощь (Help)

Справка по использованию бота с основной информацией:

- **Команды бота** - список всех доступных команд
- **Горячие клавиши** - полезные клавиши
- **Часто задаваемые вопросы** - ответы на типичные вопросы
- **Связаться с администратором** - контакт поддержки

## Профиль пользователя

### Основная информация

- **Имя пользователя** - ваше имя в Telegram
- **ID пользователя** - уникальный номер в боте
- **Адрес кошелька** - адрес вашего кошелька Solana
- **Базовая валюта** - выбранная валюта для сделок (SOL или USDC)

### Информация о подписке

- **Тип подписки** - Full или Profit Share
- **Дата подписки** - когда была активирована подписка
- **Способ активации** - способ, которым была активирована подписка
- **Статус** - активна или неактивна

### Торговая статистика

Включает:
- Количество торговых сделок
- Объём торговли (сумма всех сделок)
- Общая прибыль/убыток
- Процент выигрышей
- Дата последней активности

## Команды бота

### Основные команды

| Команда | Описание |
|---------|---------|
| `/start` | Инициализация бота и главное меню |
| `/menu` | Открыть главное меню |
| `/profile` | Открыть ваш профиль |
| `/settings` | Открыть настройки |
| `/orders` | Показать открытые ордера |
| `/stats` | Показать статистику |
| `/help` | Справка по использованию |

### Специальные команды

| Команда | Описание |
|---------|---------|
| `/status` | Статус бота и подписки |
| `/wallet` | Информация о кошельке |
| `/enable` | Включить бот |
| `/disable` | Отключить бот |

## Навигация

### Кнопки навигации

При работе с меню вы увидите кнопки навигации:

- **◀️ Назад** - вернуться в предыдущее меню
- **🏠 Главная** - вернуться в главное меню
- **⬅️ Предыдущая** - предыдущая страница (для многостраничных списков)
- **➡️ Следующая** - следующая страница (для многостраничных списков)

### Быстрые действия

Некоторые меню содержат кнопки быстрых действий:

- **✏️ Изменить** - отредактировать параметр
- **✅ Сохранить** - сохранить изменения
- **❌ Отмена** - отменить операцию
- **🔄 Обновить** - обновить данные

## Типичный рабочий процесс

1. Открыть **Главное меню** нажатием кнопки **🏠 Главная панель**
2. Проверить **Открытые ордера** для просмотра текущих позиций
3. При необходимости отредактировать **Настройки**
4. Просмотреть **Статистику** для анализа результатов
5. Вернуться в главное меню для дальнейшей работы

---

**Совет:** Используйте кнопку 🏠 Главная для быстрого возврата в главное меню из любого подменю.
