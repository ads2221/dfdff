# DCA Tracker Bot - Полное руководство пользователя

Добро пожаловать в полное руководство DCA Tracker Bot! Этот гайд предназначен для помощи вам в использовании всех функций и возможностей нашего Telegram бота для отслеживания и управления вашими торговыми позициями.

## Что такое DCA Tracker Bot?

DCA Tracker Bot - это мощный Telegram бот, который автоматизирует отслеживание и управление вашими торговыми позициями на блокчейне Solana. Бот помогает вам:

- **Отслеживать открытые позиции** в реальном времени
- **Автоматически закрывать ордера** по установленным параметрам
- **Рассчитывать прибыль/убыток (PnL)** автоматически
- **Фильтровать токены** по множеству параметров
- **Управлять кошельком** безопасно
- **Автоматизировать торговлю** согласно вашим правилам

## Быстрый старт

Если вы в спешке, вот основные шаги:

1. Нажмите `/start` для инициализации бота
2. Добавьте приватный ключ вашего кошелька в **Настройках кошелька**
3. Выберите базовую валюту (SOL или USDC)
4. Установите размер торговой позиции
5. Настройте фильтры согласно вашему стилю торговли
6. Отправьте сообщение с информацией о токене в чат бота
