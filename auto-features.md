# Автоматизация

## Введение

Автоматизация - это мощный набор функций, которые позволяют боту выполнять действия без вашего участия. Это экономит время и помогает соблюдать вашу торговую стратегию.

## Автоматическое закрытие ордеров

### Закрытие по времени (Auto-Close by Time)

Бот может автоматически закрывать ордера по истечению установленного времени.

**Как работает:**
1. Вы устанавливаете время жизни ордера (например, 480 минут)
2. Ордер остаётся открытым указанное время
3. Когда время истекает, бот закрывает позицию
4. Вы получаете уведомление с результатом

**Как включить:**
1. Откройте **⚙️ Настройки → Автоматизация → Автозакрытие по времени**
2. Нажмите **Включить**
3. Установите время в минутах:
   - 60 = 1 час
   - 240 = 4 часа
   - 480 = 8 часов
   - 1440 = 24 часа
4. Сохраните

**Пример:**
- Вы открыли ордер в 10:00
- Установили автозакрытие на 480 минут (8 часов)
- Ордер автоматически закроется в 18:00

### Раннее закрытие

Вы можете закрывать позицию раньше установленного времени.

**Как работает:**
1. Устанавливаете дополнительное время раннего закрытия
2. Позиция закроется на это количество минут раньше

**Пример:**
- Автозакрытие: 480 минут
- Раннее закрытие: 30 минут
- Результат: ордер закроется через 450 минут (30 минут раньше)

**Как выставить:**
1. Откройте **Настройки → Автоматизация → Раннее закрытие**
2. Введите количество минут
3. Оставьте 0 для отключения
4. Сохраните

## Автоматический своп SOL

### Что это такое

Когда ваше количество SOL падает ниже установленного порога, бот автоматически свапит USDC на SOL.

**Зачем это нужно:**
- SOL используется для оплаты комиссий сети (Gas Fees)
- Если SOL заканчивается, вы не можете открывать новые позиции
- Автосвап гарантирует, что у вас всегда достаточно SOL

### Как работает

1. Бот регулярно проверяет ваш баланс SOL
2. Если количество SOL меньше установленного порога
3. Автоматически свапит указанное количество USDC на SOL
4. Вы получаете уведомление об успешном свапе

**Процесс:**
```
Баланс SOL проверяется → Меньше порога?
  → Да → Своп USDC на SOL
  → Нет → Всё нормально
```

### Как включить

1. Откройте **Настройки → Автоматизация → Автоматический своп SOL**
2. Нажмите **Включить**
3. Установите параметры:
   - **Порог (Threshold):** при каком количестве SOL активировать своп
   - **Сумма для свапа (Amount):** сколько USDC свапить на SOL
4. Сохраните

### Пример конфигурации

Допустим, у вас есть 2 SOL и 1000 USDC:

**Сценарий 1: Без автосвапа**
- Вы открываете несколько ордеров
- SOL заканчивается
- Вы не можете открыть новый ордер из-за недостатка SOL для комиссии
- Проблема!

**Сценарий 2: С автосвапом**
- Порог: 1 SOL
- Сумма: $10 USDC
- Вы открываете ордера, SOL уменьшается
- Когда SOL < 1, бот автоматически свапит $10 USDC на SOL
- Проблема решена!

### Параметры автосвапа

| Параметр | Рекомендуемое значение |
|----------|-------------------|
| Порог | $1.50 - $2.00 |
| Сумма для свапа | $10 - $20 |

## Автоматический чёрный список

### Что это такое

Система автоматически добавляет токены в чёрный список при определённых условиях.

**Когда срабатывает:**
- Если токен быстро закрывается (< 1 минуты) несколько раз
- Бот добавляет его в чёрный список
- Позиции по этому токену больше не откроются

### Почему это нужно

- Защищает вас от скам токенов
- Избегает убыточных ордеров
- Автоматическое обучение системы

### Как включить

1. Откройте **Настройки → Автоматизация → Автоматический чёрный список**
2. Нажмите **Включить**
3. Установите параметры:
   - **Max Quick Closes:** максимум быстрых закрытий (3)
   - **Time Window:** окно времени в минутах (5)
   - **Quick Close Threshold:** что считается быстрым закрытием в минутах (1)
4. Сохраните

### Пример

**Параметры:**
- Max Quick Closes: 3
- Time Window: 5 минут
- Quick Close Threshold: 1 минута

**Сценарий:**
- Токен A закрывается за 30 секунд (быстрое закрытие #1)
- Токен A закрывается за 45 секунд (быстрое закрытие #2)
- Токен A закрывается за 50 секунд (быстрое закрытие #3)
- Все 3 за 5 минут
- **Результат:** Токен A добавляется в чёрный список

### Управление автоматическим чёрным списком

Вы можете просмотреть и изменить автоматически добавленные токены:

1. Откройте **Фильтры → Чёрный список → Токены**
2. Найдите токены, добавленные автоматически
3. Удалите, если нужно

## Правила изменения суммы позиции

### Что это такое

Автоматическое изменение размера позиции на основе параметров токена.

**Примеры:**
- Если общая сумма DCA > $5000, открывать позицию в $150
- Если MCap > $50M, открывать позицию в $75
- И так далее

### Как добавить правило

1. Откройте **Настройки → Автоматизация → Правила суммы позиции**
2. Нажмите **Добавить правило**
3. Установите:
   - **Название:** описание правила
   - **Сумма открытия:** размер позиции в USD
   - **Условия:** параметры, при которых применяется правило
4. Сохраните

### Условия правила

Вы можете комбинировать условия:

- **Минимальная общая сумма DCA:** минимум USD для открытия
- **Минимальный MCap:** минимальная капитализация
- **Максимальный MCap:** максимальная капитализация
- **Минимальная ликвидность:** минимальная ликвидность

**Пример правила:**
```
Название: "Большие позиции для больших DCA"
Сумма открытия: $150
Условия:
  - Min Total DCA Amount: $5000
  - Min MCap: $10,000,000
  - Max MCap: $500,000,000
  - Min Liquidity: $200,000
```

## Параметры ETA (Оценённое время действия)

### Правила для ETA

Вы можете установить разные суммы на основе ETA.

**Пример:**
- Если ETA < 15 минут: открывать позицию $100
- Если ETA 15-60 минут: открывать позицию $75
- Если ETA > 60 минут: открывать позицию $50

### Как добавить правило

1. Откройте **Настройки → Автоматизация → Правила ETA**
2. Нажмите **Добавить правило**
3. Установите диапазон ETA и сумму
4. Сохраните

## Автоматическое обновление PnL

### Что это такое

Бот автоматически обновляет показатели прибыли/убытка для всех открытых ордеров.

**Как работает:**
1. Каждые 5 минут бот проверяет цены токенов
2. Рассчитывает новый PnL для каждого ордера
3. Обновляет информацию в меню
4. Отправляет уведомления, если PnL достигает определённых значений

### Как включить

Обычно включено по умолчанию. Если нужно отключить:

1. Откройте **Настройки → Автоматизация**
2. Найдите **Автоматическое обновление PnL**
3. Отключите при необходимости

## Проблемы и решения

### Проблема: Автосвап не срабатывает

**Решение:**
- Проверьте, достаточно USDC в кошельке
- Убедитесь, что параметры правильные
- Посмотрите логи ошибок в боте

### Проблема: Слишком много токенов в автоматическом чёрном списке

**Решение:**
- Ослабьте правила автоматического чёрного списка
- Увеличьте Quick Close Threshold
- Смотрите, почему токены закрываются быстро

### Проблема: Позиции закрываются слишком рано

**Решение:**
- Увеличьте время автозакрытия
- Уменьшите раннее закрытие
- Отключите раннее закрытие полностью
