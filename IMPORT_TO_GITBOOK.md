## Способ 1: Через GitHub (Рекомендуется)

Это самый простой способ для долгосрочной синхронизации.

### Шаги:

1. **Создайте GitHub репозиторий:**
   - Перейдите на github.com
   - Создайте новый репозиторий (например, `dca-tracker-docs`)
   - Выберите "Public" для публичного доступа

2. **Загрузьте папку docs на GitHub:**
   ```bash
   cd docs
   git init
   git add .
   git commit -m "Initial commit: DCA Tracker Bot Documentation"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЮЗЕР/dca-tracker-docs.git
   git push -u origin main
   ```

3. **В GitBook:**
   - Перейдите в https://app.gitbook.com
   - Нажмите "Create new"
   - Выберите "Import from GitHub"
   - Авторизуйте доступ к GitHub
   - Выберите ваш репозиторий

4. **GitBook автоматически импортирует документацию**

## Способ 2: Прямая загрузка

Если вы хотите загрузить всю папку один раз:

### Шаги:

1. **В GitBook:**
   - Перейдите в https://app.gitbook.com
   - Нажмите "Create new"

2. **Выберите пустое пространство**
   - Вбейте название: "DCA Tracker Bot Guide"
   - Создайте

3. **Загрузите файлы:**
   - В левой панели нажмите трёхточие (⋯) рядом с названием
   - Выберите "Settings"
   - Найдите опцию "Customize" или "Import content"
   - Загрузьте все файлы markdown из папки docs

4. **Проверьте структуру:**
   - Убедитесь, что все файлы загрузились
   - Проверьте, что SUMMARY.md правильно настроен

## Способ 3: CLI (Командная строка)

Для продвинутых пользователей:

### Установка GitBook CLI:
```bash
npm install -g gitbook-cli
```

### Сборка:
```bash
cd docs
gitbook install
gitbook build
```

### Результат:
- Создастся папка `_book/` с HTML версией
- Можете загрузить на хостинг (Netlify, GitHub Pages и т.д.)

## Проверка после импорта

### Убедитесь, что всё работает:

1. **Структура меню:**
   - [ ] На левой панели видны все разделы
   - [ ] Все ссылки работают

2. **Содержимое:**

   - [ ] Таблицы отображаются корректно

## Обновление документации

### Если вы используете GitHub:

1. **Отредактируйте файлы локально**
2. **Запушьте на GitHub:**
   ```bash
   git add .
   git commit -m "Update documentation"
   git push
   ```
3. **GitBook автоматически обновится**

### Если вы используете прямую загрузку:

1. **Отредактируйте в GitBook**
2. **Или загрузите новые файлы в папку docs**

## Советы по оптимизации

### 1. Улучшьте поисковую оптимизацию:
- Используйте описательные заголовки
- Добавляйте ключевые слова естественно
- Разбивайте контент на подразделы

### 2. Структура контента:
- Один файл = одна основная тема
- Используйте заголовки для структуры
- Добавляйте таблицы оглавления в большие файлы

### 3. Форматирование:
- Используйте **жирный** для важного
- Используйте `код` для команд и параметров
- Используйте > блоки цитирования для советов

### 4. Навигация:
- Добавьте в конце каждого файла ссылку "Следующая страница"
- Используйте кросс-ссылки между разделами

## Часто встречающиеся проблемы

### Проблема: Ссылки не работают
**Решение:** Убедитесь, что все пути относительные (начинаются с `../` или имена файлов).

### Проблема: Изображения не загружаются
**Решение:** Добавьте папку `images/` и используйте `![alt](images/name.png)`

### Проблема: Меню не отображается правильно
**Решение:** Проверьте SUMMARY.md - убедитесь, что все пути правильные.

### Проблема: Поиск не работает
**Решение:** Пересоздайте пространство в GitBook или переимпортируйте из GitHub.

## Версионирование

Если вы хотите иметь несколько версий документации:

1. **Создайте ветки на GitHub:**
   ```bash
   git checkout -b v1.0
   # Отредактируйте
   git push origin v1.0
   ```

2. **В GitBook:**
   - Перейдите в Settings → Customization → Integrations
   - Добавьте ветку как отдельное пространство
