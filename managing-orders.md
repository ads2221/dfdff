# Управление ордерами

## Открытие новой позиции

### Способ 1: Отправка информации о токене в чат

Вы можете отправить информацию о токене прямо в чат бота. Бот автоматически парсит сообщение и открывает позицию, если токен проходит фильтры.

**Информация, которую должно содержать сообщение:**

- **CA (Contract Address)** - адрес контракта токена
- **Market Cap** - капитализация рынка
- **Liquidity** - ликвидность
- **Volume 24h** - объём торговли за 24 часа
- **Potential Price Change** - ожидаемый процент изменения цены
- **ETA** - время до события (в минутах)
- **Holders** - количество держателей

**Пример сообщения:**

```
CA: Ek3UW3qh5a6m8j7k2L9pQ3s5t6v7w8x9y0
Market Cap: $5,000,000
Liquidity: $200,000
Volume 24h: $500,000
Potential Price Change: 150%
ETA: 45 minutes
Holders: 1,250
```

Бот автоматически проверит информацию и откроет позицию, если:
- Значения проходят ваши фильтры
- Токен не в чёрном списке
- У вас достаточно средств в кошельке

### Способ 2: Ручное открытие позиции

1. Откройте **Главная панель → Открытые ордера**
2. Нажмите кнопку **Открыть новую позицию**
3. Введите информацию о токене:
   - Contract Address (CA)
   - Количество USD для сделки
   - Выберите время закрытия

## Просмотр деталей ордера

При нажатии на любой открытый ордер вы увидите:

### Основная информация

- **Название токена** - символ и адрес
- **Сумма позиции** - размер в USD и базовой валюте
- **Цена открытия** - цена, при которой была открыта позиция

### Текущее состояние

- **Текущая цена** - актуальная рыночная цена
- **Прибыль/Убыток** - абсолютное значение в USD
- **Процент изменения** - процентное изменение от цены открытия
- **Время открытия** - когда была открыта позиция

### Время жизни

- **Время до автозакрытия** - осталось до автоматического закрытия
- **Причина закрытия** - почему будет закрыта позиция (по времени, по профиту и т.д.)

## Закрытие позиции

### Полное закрытие

Нажмите кнопку **Закрыть полностью** для закрытия всей позиции:

1. Бот вычислит текущий PnL
2. Выполнит своп на вашем кошельке
3. Отправит уведомление с результатом
4. Ордер исчезнет из списка открытых

**Результат:**
- Вы получите токены по текущей цене
- Комиссия сети будет вычтена автоматически

### Частичное закрытие

Нажмите **Закрыть частично (%)** для закрытия части позиции:

1. Выберите процент для закрытия:
   - 25%
   - 50%
   - 75%
   - Или введите свой процент

2. Бот закроет указанный процент позиции
3. Остаток останется открытым
4. Вы получите уведомление с результатом

### Закрытие с указанием времени

Если вы хотите изменить время автоматического закрытия:

1. Нажмите на ордер
2. Выберите **Изменить время закрытия**
3. Введите новое время в минутах
4. Сохраните

## Черный список токенов

### Добавление токена в черный список

Если позиция потеряла деньги, вы можете добавить токен в черный список:

1. Откройте ордер с убыточной позицией
2. Нажмите кнопку **Добавить в черный список**
3. Выберите причину (опционально)
4. Подтвердите

**Результат:**
- Токен будет добавлен в ваш личный черный список
- Бот не будет открывать позиции по этому токену автоматически

## Отслеживание PnL (Прибыль/Убыток)

### Как рассчитывается PnL

PnL рассчитывается на основе:

1. **Цена открытия** - цена, при которой вы вошли
2. **Текущая цена** - актуальная рыночная цена
3. **Размер позиции** - сумма, которую вы инвестировали

**Формула:**
```
PnL = (Текущая цена - Цена открытия) × Количество токенов
PnL % = (PnL / Инвестированная сумма) × 100
```

### Обновление PnL

PnL обновляется в реальном времени:

- При открытии меню с ордером
- Каждые 5 минут автоматически
- При закрытии позиции

### История PnL

Вы можете просмотреть историю PnL закрытых ордеров:

1. Откройте **Профиль → История торговли**
2. Выберите период (день, неделя, месяц)
3. Увидите список закрытых позиций с результатами

## Уведомления

Бот отправляет уведомления о:

- **Открытии позиции** - подтверждение открытия ордера
- **Изменении PnL** - когда позиция достигает значимых значений (+5%, +10% и т.д.)
- **Закрытии позиции** - результат закрытия с финальным PnL
- **Ошибках** - если что-то пошло не так

### Управление уведомлениями

В **Настройки → Оповещения** вы можете:

- Включить/отключить уведомления о PnL
- Выбрать, о каких значениях получать уведомления
- Выбрать, нужны ли уведомления о закрытиях

## Статистика ордеров

### Средние показатели

Бот автоматически рассчитывает:

- **Средняя прибыль на ордер** - средний PnL
- **Средняя комиссия** - средние затраты на сеть
- **Среднее время жизни** - сколько в среднем живет ордер

### Анализ производительности

Для анализа вашей торговли посмотрите:

1. **Статистика → Открытые позиции** - текущие ордера
2. **Статистика → История** - закрытые ордера с результатами
3. **Профиль → Статистика** - общие показатели

---

**Помните:** Все операции требуют наличия средств в кошельке для оплаты комиссий сети (Gas Fees).
