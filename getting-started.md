# Первые шаги

## Инициализация бота

Чтобы начать работу с DCA Tracker Bot, выполните следующие шаги:

### Шаг 1: Запуск бота

1. Откройте Telegram и найдите бота DCA Tracker
2. Нажмите кнопку "Начать" или введите команду `/start`
3. Бот отправит вам приветственное сообщение

### Шаг 2: Добавление кошелька

После инициализации перейдите в **Настройки → Настройки кошелька** и:

1. Выберите опцию **Добавить приватный ключ**
2. Введите приватный ключ вашего кошелька Solana
3. Бот проверит ключ и отобразит адрес вашего кошелька
4. Сохраните настройки

### Шаг 3: Выбор базовой валюты

В **Настройках торговли** выберите базовую валюту:

- **SOL** - рекомендуется для большинства пользователей
- **USDC** - для стабильной валюты

### Шаг 4: Установка размера позиции

Установите стандартный размер торговой позиции в долларах США (USD).

> **Примечание:** Эту сумму можно менять перед каждой торговлей.

### Шаг 5: Настройка фильтров

Установите базовые фильтры для отбора токенов, которыми хотите торговать.

## Структура интерфейса

### Главное меню

Главное меню содержит следующие разделы:

| Кнопка | Описание |
|--------|---------|
| 🏠 Главная панель | Основное меню со всеми опциями |
| 👤 Профиль | Ваша информация и статистика |
| ⚙️ Настройки | Все параметры и конфигурация |
| 📊 Статистика | Результаты торговли |
| ℹ️ Помощь | Справка по использованию |

### Подменю настроек

- **Настройки кошелька** - управление кошельком
- **Настройки торговли** - параметры торговли
- **Фильтры** - отбор токенов
- **Автоматизация** - автоматические действия
- **Расширенные** - продвинутые функции

## Основные концепции

### Открытые ордера

Открытый ордер - это активная позиция, которую вы открыли. Бот отслеживает все открытые ордера и показывает:

- Текущую цену
- Вашу прибыль/убыток
- Когда позиция будет закрыта

### Фильтры

Фильтры позволяют автоматически отбирать только те токены, которые соответствуют вашим критериям:

- Капитализация рынка (Market Cap)
- Ликвидность
- Объём торговли за 24 часа
- Процент изменения цены
- И многое другое

### Автоматизация

Автоматизация позволяет боту выполнять действия без вашего участия:

- Автоматическое закрытие ордеров по времени
- Автоматический своп SOL
- Автоматическое добавление токенов в чёрный список
