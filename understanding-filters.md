# Понимание фильтров

## Введение

Фильтры - это правила, которые определяют, какие токены бот будет игнорировать или принимать. Без правильных фильтров вы можете получить много убыточных сделок.

## Что такое фильтры

Фильтры - это набор критериев, которые токен должен соответствовать для открытия позиции:

- **Минимальная капитализация** - токен должен быть достаточно большим
- **Максимальная капитализация** - токен не должен быть слишком большим
- **Минимальная ликвидность** - должно быть достаточно ликвидности
- **Объем торговли** - должна быть активная торговля
- **Процент изменения** - ожидаемый рост
- И многое другое

## Основные параметры фильтров

### Капитализация рынка (Market Cap)

Капитализация рынка = цена токена × общее количество токенов

**Минимальная капитализация (Min MCap)**

Токены с низкой капитализацией более волатильны и рискованны.

| Market Cap | Тип токена | Риск | Рекомендация |
|-----------|-----------|------|-------------|
| < $1M | Очень новые | Очень высокий | Не рекомендуется |
| $1M - $5M | Молодые | Высокий | Только опытным |
| $5M - $50M | Растущие | Средний | Хороший выбор |
| $50M+ | Зрелые | Низкий | Безопаснее |

**Как выставить:**
1. Откройте **⚙️ Настройки → Фильтры → Market Cap**
2. Выберите или введите минимум
3. Рекомендуется: **$3,000,000** (от 3M)
4. Сохраните

**Максимальная капитализация (Max MCap)**

Некоторые трейдеры не открывают позиции по токенам с очень высокой капитализацией.

**Рекомендуется:** $800,000,000 (800M) или больше для открытости

### Ликвидность (Liquidity)

Ликвидность - это сумма денег, которая может быть использована для торговли токеном.

**Как работает:**
- Низкая ликвидность = сложнее продать токен
- Высокая ликвидность = легче войти и выйти

**Рекомендуемые значения:**

| Ликвидность | Рекомендация |
|------------|-------------|
| < $50K | Опасно |
| $50K - $150K | Низко |
| $150K - $500K | Нормально |
| > $500K | Хорошо |

**Как выставить:**
1. Откройте **Фильтры → Liquidity**
2. Установите минимум: **$150,000**
3. Сохраните

### Объем торговли за 24 часа (Volume 24h)

Объем - это сумма денег, торгуемых за последние 24 часа.

**Как работает:**
- Высокий объем = токен популярен и активно торгуется
- Низкий объем = никто не торгует этим токеном

**Рекомендуемые значения:**

| Volume 24h | Активность |
|-----------|-----------|
| < $10K | Очень низкая |
| $10K - $100K | Низкая |
| $100K - $1M | Средняя |
| > $1M | Высокая |

**Как выставить:**
1. Откройте **Фильтры → Volume 24h**
2. Установите минимум: **$0** (без минимума) или **$100,000** (для активных)
3. Сохраните

### Процент изменения цены (Potential Price Change)

Ожидаемый процент, на который может измениться цена.

**Как работает:**
- Более высокий процент = больше потенциал для прибыли
- Но и больше риск

**Рекомендуемые значения:**

| Процент | Тип торговца |
|--------|-------------|
| 0% - 50% | Консервативный |
| 50% - 200% | Средний |
| 200%+ | Агрессивный |

**Как выставить:**
1. Откройте **Фильтры → Potential Price Change**
2. Установите минимум: **0%** или **50%**
3. Максимум: не ограничиваем
4. Сохраните

### Количество держателей (Holders)

Количество адресов, которые владеют этим токеном.

**Как работает:**
- Много держателей = более распределённый токен
- Мало держателей = может быть скам или концентрация у одного

**Рекомендуемые значения:**

| Holders | Качество |
|--------|---------|
| < 50 | Опасно |
| 50 - 500 | Рискованно |
| 500 - 2000 | Нормально |
| > 2000 | Хорошо |

**Как выставить:**
1. Откройте **Фильтры → Holders**
2. Установите минимум: **0** (обычно)
3. Максимум: не ограничиваем
4. Сохраните

## Временные параметры

### ETA (Estimated Time of Action)

Время до события (обычно до запуска на DEX).

**Как работает:**
- Короче ETA = скорее событие
- Дольше ETA = больше времени на подготовку

**Рекомендуемые значения:**

| ETA | Значение |
|-----|---------|
| Min ETA | 3 минуты |
| Max ETA | 850 минут (14.2 часа) |

**Как выставить:**
1. Откройте **Фильтры → ETA**
2. Min: **3** минуты
3. Max: **850** минут
4. Сохраните

### Частота (Frequency)

Как часто обновляется информация о токене.

**Как работает:**
- Высокая частота = много трейдеров интересуются
- Низкая частота = мало активности

**Рекомендуемое значение:** **500** (обычно)

## Комбинированные фильтры

### Правила MCap & Frequency

Правила, которые комбинируют Mcap и Frequency.

**Пример правила:**
- Если MCap < $15M, то Frequency должна быть > 390
- Если MCap > $15M, то Frequency должна быть > 500

**Как добавить:**
1. Откройте **Фильтры → Расширенные → MCap & Frequency Rules**
2. Нажмите **Добавить правило**
3. Установите:
   - Условие MCap (< или >)
   - Значение MCap
   - Требуемая Frequency
4. Сохраните

### Специфичные правила для токенов (Token-Specific Rules)

Специальные правила для конкретных токенов.

**Как использовать:**
- Добавить токен в черный список
- Добавить специальное правило для токена
- Ограничить позицию по токену

## Чёрные списки

### Чёрный список токенов

Токены в чёрном списке никогда не откроют позицию.

**Как добавить:**
1. Откройте **Фильтры → Чёрные списки → Токены**
2. Нажмите **Добавить токен**
3. Введите адрес контракта (CA)
4. Выберите причину (опционально)
5. Сохраните

**Причины для добавления:**
- Скам токен
- Убыточные сделки с этим токеном
- Известный рыг

### Чёрный список пользователей

Игнорировать сообщения от определённых пользователей.

**Как добавить:**
1. Откройте **Фильтры → Чёрные списки → Пользователи**
2. Нажмите **Добавить пользователя**
3. Введите username пользователя
4. Сохраните

## Автоматический чёрный список

### Что такое автоматический чёрный список

Система автоматически добавляет токены в чёрный список при определённых условиях.

**Как работает:**
1. Если токен быстро закрывается (< 1 минуты) N раз
2. Бот автоматически добавляет его в чёрный список
3. Вы получаете уведомление

**Как включить:**
1. Откройте **Фильтры → Автоматический чёрный список**
2. Нажмите **Включить**
3. Установите:
   - **Max Quick Closes:** 3 (максимум быстрых закрытий)
   - **Time Window:** 5 (минут)
   - **Quick Close Threshold:** 1 (минута)
4. Сохраните

**Пример:**
- Токен закроется 3+ раза за менее 1 минуты
- За период 5 минут
- Бот автоматически добавит его в чёрный список

## Типовые конфигурации

### Консервативный трейдер

Фильтры для минимизации рисков:

```
Min MCap: $10,000,000
Max MCap: $800,000,000
Min Liquidity: $500,000
Min Volume 24h: $500,000
Min Holders: 500
Potential Price Change: 50% - 500%
```

### Средний трейдер

Баланс между риском и доходностью:

```
Min MCap: $3,000,000
Max MCap: $800,000,000
Min Liquidity: $150,000
Min Volume 24h: $0
Min Holders: 0
Potential Price Change: 0% - 1000%
```

### Агрессивный трейдер

Более рискованная стратегия:

```
Min MCap: $1,000,000
Max MCap: $800,000,000
Min Liquidity: $50,000
Min Volume 24h: $0
Min Holders: 0
Potential Price Change: 0% - 10000%
```

## Оптимизация фильтров

### Как выбрать правильные фильтры

1. **Начните с консервативных фильтров**
2. **Отслеживайте результаты 20-30 сделок**
3. **Анализируйте убыточные сделки:**
   - Какие параметры были общими?
   - Какой фильтр помог бы их избежать?
4. **Добавляйте или усиливайте фильтры**
5. **Повторяйте процесс**

### Когда ослаблять фильтры

- Если упускаете много хороших сделок
- Если процент выигрышей высокий, но мало сделок

### Когда усиливать фильтры

- Если много убыточных сделок
- Если процент выигрышей низкий

## Тестирование фильтров

### Режим тестирования

Вы можете создать тестовую конфигурацию фильтров:

1. Откройте **Фильтры → Расширенные → Сохранить как шаблон**
2. Назовите шаблон (например, "Консервативный")
3. Сохраните

Позже вы можете быстро переключаться между шаблонами фильтров.

---

**Совет:** Не меняйте фильтры часто. Дайте боту минимум 20-30 сделок, чтобы оценить эффективность текущих фильтров.
