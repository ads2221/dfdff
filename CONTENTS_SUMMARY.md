## 📖 Как использовать

### Быстрый импорт:

1. **Скопируйте папку `docs/`** в ваш проект
2. **Следуйте инструкциям** в файле `IMPORT_TO_GITBOOK.md`
3. **Выберите один из трёх способов:**
   - Импорт через GitHub (рекомендуется)
   - Прямая загрузка в GitBook
   - Использование GitBook CLI

### Структура для GitBook:

```
docs/ (эта папка)
├── SUMMARY.md          ← Обязательно (структура меню)
├── README.md           ← Главная страница
├── .gitbook.yaml       ← Конфигурация
```
